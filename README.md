# 一隅 · 我的本地小站

首页、日志、2048 小游戏和文献阅读，先全部放在自己的电脑上。无需登录、不购买服务器，不会将个人内容上传到外网。原来的账号和部署代码仍然保留，之后可以继续升级。

## 打开网站

1. 双击本文件夹中的 **启动小站.cmd**。
2. 保持启动窗口开着，在浏览器打开 **http://127.0.0.1:4317**。
3. 点击导航里的「文献库」，选择「导入 PDF」，或将文件拖到文献库页面。

关闭启动窗口会停止小站；下次重新启动，已保存的文献、日志和笔记仍然存在。启动程序会使用已有的 Node.js 24；换电脑时需要安装 Node.js 24 或更高版本。也可以在本文件夹运行 `npm start`，不需要安装 npm 依赖。

文献库需要通过启动程序打开。直接双击 index.html 仍可使用旧的浏览器本地日志与游戏，但不能把 PDF 存入电脑文件夹。

## 文献库与 PDF 阅读

- 支持批量选择 PDF、拖放导入，每份最大 80 MB。
- 导入会复制一份 PDF 到小站，不会移动或修改你原来的文件。
- 相同内容自动去重，保留原有笔记和阅读位置；重新导入已移入回收站的文献会恢复它。
- 在网页中翻页、输入页码、缩放、旋转、展开阅读器和下载原 PDF。
- 已渲染页面可以选中文字复制；阅读器内的文字 PDF 保留文字层。扫描图片 PDF 可以阅读，但此版本不提供 OCR。
- 阅读位置自动保存，重新打开后继续上次的页码。信息与笔记需要点击「保存信息与笔记」。
- 可填写标题、作者、年份和标签，按这些信息搜索；支持收藏和回收站恢复。
- 带密码的 PDF 会在阅读时要求输入密码，密码不会保存到文献库。
- 阅读器使用本地的 Mozilla PDF.js 6.4.299，字体和解码器也已放在 vendor/pdfjs 中；日常阅读不依赖 CDN 或外网。使用近期版本的 Chrome 或 Edge。

未保存的笔记在切换文献或关闭网页前会提醒。遇到其他窗口修改同一份笔记时，后台会拒绝旧版本覆盖，并保留当前编辑内容。

## 文件保存在哪里

| 内容 | 默认保存位置 |
| --- | --- |
| PDF 原文件的本地副本 | data/papers/<文献编号>.pdf |
| 文献标题、作者、标签、笔记和阅读页码 | data/site.sqlite |
| 本地首页、便签、日志与游戏进度 | data/site.sqlite |
| 离线阅读器代码和资源 | vendor/pdfjs/ |

文献编号是小站生成的文件名，原来的中文文件名保存在数据库中，下载时仍使用原文件名。不要单独重命名 data/papers 中的文件。

**备份方法：先关闭小站启动窗口，再复制整个 data 文件夹到其他位置。** 恢复时也先停止小站，再恢复完整文件夹。数据库可能有 WAL/SHM 辅助文件，不要只复制正在运行的 site.sqlite。个人日志仍可单独导出 JSON，PDF 也能逐份下载。

本地服务只监听 127.0.0.1，只在这台电脑上访问。持有电脑文件访问权限的人仍可读取 data 中的内容；它不是文件加密保险箱。PDF 文件、数据库、后台源代码和环境配置不会通过静态接口直接公开下载。

## 日志和小游戏

日志支持新建、编辑、搜索、月份筛选、回收站恢复和 JSON 导入导出。2048 支持方向键、W/A/S/D、棋盘滑动或方向按钮、撤回一步和重新开始。

旧版直接打开 HTML 留下的浏览器记录不会自动迁移或删除。在原来使用的浏览器/地址中导出日志，再在本地启动的网站中导入即可。此前账号模式的数据也仍保留在数据库里，本地记录与账号记录分开存放。

## 之后再升级

现在没有创建任何线上服务。邮箱/密码的账号模式和 Render / Docker 配置作为后续升级基础保留，详见 DEPLOY.md。文献共享尚未实现；之后需要加文件存储、逐账号权限与迁移工具。

开发时可使用 `npm run start:accounts` 启动此前的账号模式；当前文献库只在本地模式使用。账号模式仍未接入邮箱验证和自助密码找回。

## 开发与检查

```powershell
npm start
npm test
```

修改前端或后台文件后，需要重启小站并刷新页面。

- server.mjs：启动、账号模式和静态资源服务。
- local-library.mjs：本地记录、PDF 文件存储、文献信息与阅读进度接口。
- library.js / library.css：文献书架与 PDF 阅读器。
- vendor/pdfjs/：本地阅读器及其许可证。
- account.js：本地存储和账号存储的统一接口。
- app.js / journal.js / games.js：首页、日志与小游戏。
- tests/：账号隔离、文献存储/重启恢复与游戏规则检查。

自动检查使用临时文件夹，网页阅读测试使用独立的测试数据库与合成 PDF，不会把测试文献混入你的正式文献库。
