# 一隅 · 私人小站

一个可以慢慢扩展的个人小站，包含首页和日志本。没有框架或外部依赖。

## 打开网站

双击本文件夹中的 `index.html`，即可用浏览器打开。

首页可以：

- 点击「装扮首页」，修改小站名字和介绍。
- 点击「写下第一个想法」，留下或修改一张便签。
- 展开三个方向卡片，看看以后想加入什么内容。
- 点击导航中的「日志」，打开自己的日志本。

名字、介绍、便签和日志存储在当前浏览器的本地存储中，不会上传。不同浏览器、不同设备，以及直接打开文件和通过本地服务器访问时，这些内容各自独立。清理浏览器数据可能会删除它们。网站目前没有上线，也没有远程同步。

## 使用日志

- 「写一篇日志」：填写记录日期和正文，标题可选。可以一天写多篇，也可以补写之前的日期。
- 点击日志列表查看全文；日志按记录日期从新到旧排列。
- 「编辑日志」：修改标题、日期或正文。
- 「移到回收站」：收起日志。在「回收站」中可以恢复，不会永久删除。
- 搜索标题或正文，也可以按月份筛选。
- 首页显示最近一篇日志的摘要。

没有保存的修改在关闭编辑窗口前会提醒；如果浏览器保存失败，编辑窗口会保留正文。

### 备份与迁移

点击日志页的「导出备份」下载 JSON 文件，包含所有日志及回收站内容。建议定期导出，并放到可靠的位置。只有浏览器本地存储里的日志不会自动写入这个项目文件夹。

在同一个或另一个浏览器打开网站后，点击「导入备份」并选择小站导出的 JSON 文件即可还原。导入会合并日志、跳过相同内容；不会覆盖已有日志。重复编号但内容不同的日志会作为独立记录保留。文件大小上限为 10 MB，日志总数上限为 10,000 篇，每篇正文上限为 30,000 字符。

## 文件

- `index.html`：页面内容和结构。
- `styles.css`：颜色、字体、布局和手机适配。
- `app.js`：便签、首页设置、日期和导航。
- `journal.js`：日志保存、搜索、月份筛选、回收站和备份导入导出。
- `journal.css`：日志页与编辑窗口的布局。

如果想永久修改网站的默认名字和介绍，可以修改 `app.js` 顶部的 `defaults`；首次加载时的静态文字也在 `index.html` 中。已有的浏览器设置会优先显示。

## 本地预览（可选）

不需要安装依赖。如已安装 Python，在此文件夹运行：

```powershell
python -m http.server 4317 --bind 127.0.0.1
```

随后打开 `http://127.0.0.1:4317`。按 `Ctrl+C` 停止。

## 之后怎么继续

先使用这个首页。想到用途时，可以直接提出具体需求，例如：

- 「增加一个读书笔记页面」
- 「加入我的个人介绍和作品」
- 「做一个网站收藏夹」
- 「换成深色风格」

到那时再增加对应功能即可。
